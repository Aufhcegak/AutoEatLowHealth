# 濒死自动进食 (Auto Eat Low Health)

星露谷物语 Mod - 血量低于阈值时自动弹出进食询问，选择期间无敌，可设置优先吃的食物。

## 功能

- **自动检测**：血量低于设定阈值时自动弹出进食对话框
- **无敌帧**：选择食物期间进入无敌状态，防止被围殴致死
- **优先级设置**：可设置多种食物的进食优先级
- **联机可用**：支持多人游戏

## 安装

1. 安装 [SMAPI](https://smapi.io/)
2. 下载本 Mod 解压到 `Stardew Valley/Mods/` 目录
3. 运行游戏

## 配置

使用 Generic Mod Config Menu 设置：
- 触发血量阈值（默认 20%）
- 无敌帧开关
- 弹窗冷却时间

输入控制台命令 `eat_priority` 打开食物优先级设置界面。
